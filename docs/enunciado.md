# Enunciado del proyecto final (bootcamp)

> Copia de referencia. Este documento manda sobre la nota: cualquier decisión
> de alcance se contrasta contra él.

## Objetivo del proyecto

Crear una aplicación web funcional, bien documentada y presentada, que cumpla
con los requisitos técnicos y metodológicos establecidos y aprendidos durante
el bootcamp. Este proyecto simula un entorno profesional, por lo que se
valorará tanto el producto final como el proceso de desarrollo.

## Requisitos mínimos solicitados

- Producto mínimo viable (PMV) funcional
- Presentación oral del proceso (máx. 15 minutos)
- Diseño en Figma (Sketch, Mockup, Prototipo)
- Gestión del proyecto en JIRA (cronograma, backlog, sprints)
- Diagramas técnicos (base de datos y clases)
- Archivo README bien estructurado (ver ejemplos proporcionados)
- Frontend en Vue, responsive (Mobile y Desktop)
- Backend en Java con Spring utilizando: Spring Boot y Spring Security
- Base de datos dockerizada (MySQL o PostgreSQL)
- API REST con login y registro de usuarios

## Entregables

- Enlace público al repositorio de Frontend
- Enlace público al repositorio de Backend
- Enlace público a la presentación realizada (puede estar en el README)

## Criterios de evaluación

| Criterio | Puntos |
|---|---|
| PMV totalmente funcional (sin errores graves) | 10 |
| Presentación del proceso (flujo de trabajo con claridad) | 10 |
| Diseño en Figma (bocetos, mockups y prototipo) | 5 |
| Gestión con JIRA (tareas y tiempos) | 10 |
| Diagramas técnicos (draw.io o Mermaid) | 10 |
| README estructurado (instalación, uso, etc.) | 10 |
| Frontend con Vue (componentes, hooks, tests de componentes, responsive) | 20 |
| Backend con Spring (seguridad, API REST, BD externa con Docker, tests unitarios y de integración) | 25 |

## Consejos durante el desarrollo

- Versiona tu código con Git y sube tu proyecto a GitHub
- Documenta todo lo que hagas, incluso decisiones técnicas
- Haz pruebas antes de entregar: funcionales, de integración, etc.

## Consejos para la presentación

- Prepara una diapositiva por cada etapa del desarrollo
- Primero qué es el producto, luego demo visual, finalmente el proceso
- Explica qué hiciste, cómo lo hiciste y por qué
- Practica para no exceder los 15 minutos
